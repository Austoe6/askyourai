# askyourai

Static site for [askyourai.com](https://askyourai.com). Members get the signal. Technical how-tos go to their own AI.

## Deploy

Import this repo on [Vercel](https://vercel.com). Framework preset: Other. No build command. Output is the repository root.

Then add the domain `askyourai.com` under Project Settings → Domains, and point DNS at Vercel.
